# 潮汐农场（Tide Farm）

《潮汐农场》是一款计划用 Devin Bot 开发的网页种田小游戏。白天挖水沟、开关闸门，晚上潮水沿低地灌入农田。海稻需要泡水才能成熟，番茄泡一次就会枯萎。玩家要在三天内收获海稻，用它跟木匠换闸门，在第三晚的大潮中保住番茄。

当前状态：项目规划中，尚未实现或部署。

## Demo 范围

使用 Vite、TypeScript 和原生 Canvas 2D。首版只做一张 16×12 固定地图、两种作物和三天关卡，不做后端、存档或正式美术。白天可预览当晚的淹水范围，点击「结束一天」后结算。

## 给 Devin Bot 的三步任务

### 1. 搭出可操作的农场

用二维数组存地图，每格记录地形、高度、作物和闸门状态。西边种海稻，东边种番茄。玩家可以在指定地块挖沟（降低一档高度），也可以开关闸门。界面显示当前天数、当晚水位和淹水预览。

### 2. 实现潮汐和作物结算

实现独立的 `simulateTide(map, tideLevel)`：从地图边缘的海水入口开始做四邻域广度优先搜索（BFS），只进入低于水位的可通行格子。关闭的闸门挡水，海水不能从对角线穿过。预览和实际结算共用这个函数。海稻累计泡水两晚后成熟，番茄泡水一次即枯萎。

### 3. 串起三天关卡并验收

前两晚开旧闸，海水只淹西田。第三天早上，玩家收获成熟海稻，找木匠换一扇新闸门。第三晚的大潮会沿北侧支沟绕过旧闸，流向东田。玩家可以提前在支沟装上新闸门并关闭，保住番茄。

验收用同一张地图：
- 前两晚打开旧闸，第三天早上能收获海稻；前两晚都关闸，则没有成熟海稻可收。
- 第三晚不封北侧支沟，东田番茄枯萎；封住后，番茄存活。
- 白天的淹水预览和当晚实际淹水范围一致。

交付：可本地运行的源码、启动命令，以及一份从第一天玩到第三天结算的试玩步骤。
